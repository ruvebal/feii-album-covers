# KTX2 choice — YHLQMDLG (`/covers/yhlqmdlg`)

Album, and the source picture's licence: Bad Bunny — *YHLQMDLG* (2020, ℗ 2020 Rimas Entertainment LLC).
Artwork creator and source: official album cover artwork (`covers/yhlqmdlg/public/sleeve.png`, 1024 × 1024 8-bit sRGB PNG). `covers/yhlqmdlg/public/thumbnail.svg` is original vector art authored for this route.
Right to publish and adapt: non-commercial academic/educational work for FE II Units 8–9 at UDIT. Audio previews (30 s) are streamed dynamically via Apple Music / iTunes Search API (`collectionId: 1500776322`) with a procedural Web Audio API dembow synthesizer fallback; no copyrighted audio files are hosted in the repository.

Chosen mode: **UASTC** (`sleeve-uastc.ktx2`) as the default sleeve texture, with a live in-app switcher (`⚡ KTX2 & GPU`) allowing real-time comparison against **ETC1S** (`sleeve-etc1s.ktx2`) and **Source PNG** (`sleeve.png`).
Why it fits this sleeve: *YHLQMDLG*'s photograph combines fine nocturnal asphalt grain, dark shadow gradients, high-contrast neon signage, and the detailed facial features and third eye on the child's forehead. While ETC1S reduces disk size by ~90% (`187,609 B`) and VRAM by 8× (`699,056 B`), its block compression introduces visible banding in the dark night sky and softens the third eye at close Studio zoom. UASTC (`--zcmp 18`) cuts GPU memory by 4× compared to the unpacked PNG (`1,398,112 B` vs `5,592,404 B` across all 11 mip levels) while preserving crisp detail on the third eye, bicycle spokes, and neon gradients.

Measured on (machine, browser, date): Linux x86_64, Chrome / WebGL 2 (and verified with `toktx` / `ktx info` v4.4.2 + `src/lib/gpuBytes.js`), 2026-11-05.
Levels counted: **all levels on every row** (11 mip levels: `1024²` down to `1²`). Level 0 (`1024²`) alone, for reference: Source PNG `4,194,304 B` · ETC1S `524,288 B` · UASTC `1,048,576 B`.

**Texture count** (`renderer.info.memory.textures`, a count, not bytes), before and after the sleeve loads: `1 → 2`. Switching between `KTX2 UASTC`, `KTX2 ETC1S`, and `Source PNG` in the HUD disposes the previous texture (`texture.dispose()` in `VinylStage.jsx`), so the resident texture count stays at `2` across mode switches.

**Orientation check:** Both `.ktx2` files were encoded with `--lower_left_maps_to_s0t0` via `npm run encode -- yhlqmdlg` (`scripts/encode-cover.mjs`). `ktx info` confirms `KTXorientation: ru` on both files, so `uv (0,0)` lands at bottom-left and the album cover renders upright in three.js without any `1.0 - vUv.y` shader hack.

**colorSpace check:** Both `.ktx2` files were encoded with `--assign_oetf srgb` (`ktx info` confirms `Transfer: KHR_DF_TRANSFER_SRGB`). After loading through `useKTX2Texture` (`src/lib/ktx2.js`) or `useTexture` (`sleevePicture.js`), `texture.colorSpace` logs `'srgb'` (`texture.colorSpace === SRGBColorSpace: ok`) and our custom shader (`YhlqmdlgMaterial.jsx`) ends with `#include <colorspace_fragment>`.

## Encoding commands & verification (`2026-11-05`)

Generated with Khronos **KTX-Software v4.4.2** (`toktx` and `ktx`) via `npm run encode -- yhlqmdlg`:

```bash
toktx --t2 --encode etc1s --genmipmap --lower_left_maps_to_s0t0 --assign_oetf srgb \
  covers/yhlqmdlg/public/sleeve-etc1s.ktx2 covers/yhlqmdlg/public/sleeve.png

toktx --t2 --encode uastc --zcmp 18 --genmipmap --lower_left_maps_to_s0t0 --assign_oetf srgb \
  covers/yhlqmdlg/public/sleeve-uastc.ktx2 covers/yhlqmdlg/public/sleeve.png
```
