# KTX2 choice

N/A. This route loads a glTF model and does not currently load GPU textures through KTX2/Basis.

## Asset rights

- `public/models/bia-combined.glb` includes the glass scene sourced from
  [Empty Glass 01 on CGTrader](https://www.cgtrader.com/free-3d-models/furniture/tableware/empty-glass-01).
  Retain the source URL and its free-model licence terms with this route.
- `public/models/bia_hand.glb` comes from
  [Blend Swap asset #22269](http://www.blendswap.com/blend/22269) and is
  released under [Creative Commons Zero 1.0](https://creativecommons.org/publicdomain/zero/1.0/).
  The archived licence evidence is
  [`docs/licenses/bia-hand-license.html`](licenses/bia-hand-license.html).
- `public/models/bia_ls_2.glb`, `public/bia-signature.png`, the route code,
  and the Six Caps font usage are original project assets.
- The Spotify iframe is an external player; its album artwork is not copied
  into this repository.

This route does not use KTX2/Basis, so there are no KTX2 file or GPU-byte
measurements to report.
