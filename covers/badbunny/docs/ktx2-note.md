# KTX2 choice — Bad Bunny (`/covers/badbunny`)

Albums & source pictures' licences:
- Bad Bunny — *YHLQMDLG* (2020), *El Último Tour Del Mundo* (2020), *Un Verano Sin Ti* (2022), and *DTmF / DeBÍ TiRAR MáS FOToS* (2025), ℗ Rimas Entertainment LLC.
- Artwork source: official album cover artwork in `covers/badbunny/public/` (`sleeve.png` 1024 × 1024 8-bit sRGB PNG encoded to `sleeve-uastc.ktx2` and `sleeve-etc1s.ktx2`, plus `dtmf.png`, `uvst.jpg`, and `eutdm.jpg` for the multi-album vinyl fan and studio wall frames). `covers/badbunny/public/thumbnail.svg` is original vector art authored for this route.
- Right to publish and adapt: non-commercial academic/educational work for FE II Units 8–9 at UDIT. Audio previews (30 s) are streamed dynamically via Apple Music / iTunes Search API (`collectionId: 1500776322`, `1787022393`, `1622045624`, `1542061935`) with a procedural Web Audio API dembow synthesizer fallback; no copyrighted audio files are hosted in the repository.

Chosen mode: **UASTC** (`sleeve-uastc.ktx2`) loaded via `useBadBunnyKtx2('uastc')` (`covers/badbunny/src/sleevePicture.js`).
Why it fits this cover: *YHLQMDLG*'s photograph combines fine nocturnal asphalt grain, dark shadow gradients, high-contrast signage, and detailed facial features. While ETC1S reduces disk size by ~90% (`187,609 B`) and VRAM by 8× (`699,056 B`), its block compression introduces visible banding in dark night gradients at close turntable zoom. UASTC (`--zcmp 18`) cuts GPU memory by 4× compared to the unpacked PNG (`1,398,112 B` vs `5,592,404 B` across all 11 mip levels) while preserving crisp detail on the spinning turntable center label.

Measured on (machine, browser, date): Linux x86_64, Chrome / WebGL 2 (and verified with `toktx` / `ktx info` v4.4.2 + `src/lib/gpuBytes.js`), 2026-11-17.
Levels counted: **all levels on every row** (11 mip levels: `1024²` down to `1²`). Level 0 (`1024²`) alone, for reference: Source PNG `4,194,304 B` · ETC1S `524,288 B` · UASTC `1,048,576 B`.

| Asset | File bytes (on disk) | GPU bytes (computed, all 11 mips) | texture.format | Observation |
| --- | ---: | ---: | --- | --- |
| Source PNG (`sleeve.png`) | 1,850,298 | 5,592,404 | `RGBAFormat` | Unpacked on upload: `1024 × 1024 × 4` (`4,194,304 B`) for level 0 plus 10 mipmap levels generated by three.js (`5,592,404 B` total). |
| ETC1S (`sleeve-etc1s.ktx2`) | 187,609 | 699,056 | `RGB_ETC2_Format` (or `RGBA_BPTC_Format` on desktop BC7 GPUs) | Smallest file on disk (~10.1% of PNG) and smallest VRAM footprint (1/8 of PNG when transcoded to 4 bpp ETC2). Slight block artifacts in dark night gradients. |
| UASTC (`sleeve-uastc.ktx2`) | 1,345,938 | 1,398,112 | `RGBA_ASTC_4x4_Format` (or `RGBA_BPTC_Format`) | Encoded with `--zcmp 18`. 27.3% smaller file on disk than PNG and 4× smaller in GPU VRAM (`1,398,112 B` vs `5,592,404 B`). Preserves sharpness and night gradients. |

**Texture count & disposal:** The KTX2 center label texture is disposed on unmount inside `Ktx2LabelBranch` (`BlenderWorld.jsx`), keeping GPU memory clean across route switches.

**Orientation check:** Both `.ktx2` files were encoded with `--lower_left_maps_to_s0t0` via `npm run encode -- badbunny` (`scripts/encode-cover.mjs`). `ktx info` confirms `KTXorientation: ru` on both files, so `uv (0,0)` lands at bottom-left and the album cover renders upright in three.js without any `1.0 - vUv.y` shader hack.

**colorSpace check:** Both `.ktx2` files were encoded with `--assign_oetf srgb` (`ktx info` confirms `Transfer: KHR_DF_TRANSFER_SRGB`). After loading through `useKTX2Texture` (`src/lib/ktx2.js`), `texture.colorSpace` logs `'srgb'` and our custom shader (`YhlqmdlgMaterial.jsx`) ends with `#include <colorspace_fragment>`.

## Encoding commands & verification

Generated with Khronos **KTX-Software v4.4.2** (`toktx` and `ktx`) via `npm run encode -- badbunny`:

```bash
toktx --t2 --encode etc1s --genmipmap --lower_left_maps_to_s0t0 --assign_oetf srgb \
  covers/badbunny/public/sleeve-etc1s.ktx2 covers/badbunny/public/sleeve.png

toktx --t2 --encode uastc --zcmp 18 --genmipmap --lower_left_maps_to_s0t0 --assign_oetf srgb \
  covers/badbunny/public/sleeve-uastc.ktx2 covers/badbunny/public/sleeve.png
```
